# Collapsible Navigation for BB

A BB plugin that replaces the sidebar navigation with an upward-folding collapsible panel.

## Features

- **Collapsible upward**: Smoothly collapse the navigation panel into a 28px top strip to give maximum vertical space to threads.
- **Quick actions**: Start a new thread or search directly from the collapsed bar.
- **Full BB Navigation integration**: Supports split view drag-and-drop, shortcut keys, item accessories, and customization.
- **Header integration**: Also provides a header slot to place navigation icons directly beside the window controls.
